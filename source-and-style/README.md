# Website Assessment

**Website:** [The Magnus Archives transcripts](https://snarp.github.io/magnus_archives_transcripts/)
This is a website hosting all of the transcripts for the audio drama, The Magnus Archives.  It's not offical (as the website title emphasizes), but is the go-to place for basically anyone in the TMA fandom looking for transcripts.  

## Coding languages used: 
HTML - I know this was used because at the top of the inspect element window, it says `<!DOCTYPE html>` which pretty definitively indicates HTML. 
CSS - It also uses CSS for the style.  You can see this in the 'Style Editor' tab of the inspect element window.  Right at the top it says `main.css` and `content_script.css`.  
Javascript - There are two JS codes for this that I was able to find.  The first is a "spoiler" JS, which will apply a `spoiler-hidden` to all elements with the class `spoiler`.  The other is a light/dark mode script.  

## Author: 
Seems to be all one guy, who goes by the username [Snarp](https://snarp.github.io/)!  The hyperlink there leads to a collection of links, which includes their email, Discord account, GitHub, and their *AO3 account????*  
In the footer, they also clarified that the transcripts are "Mostly converted versions of the official transcripts; the rest have links to the source/transcriber."  So it seems like this is one person (Snarp) finding transcripts that other people have written (both official and non-official) and formatting them to be consistent with each other and hosting them all in one spot.

I didn't use any.
