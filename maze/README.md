## The Magnus Archives Maze - Jack Miller

Using episodes from the horror podcast The Magnus Archives, the goal of this maze is to follow all the clues through to their end. 

To get started, `Enter` the maze and select your first `Clue`. Supplemental materials have been provided to familiarize or refresh you on the `Statements`.  

If you are using PowerShell, don't forget to run `.\hide-dotfiles.ps1`! If your computer is stubborn, try out: 
`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\hide-dotfiles.ps1`

Helpful commands: 

- `ls` — list files and directories
- `ls -a` — show hidden files and directories
- `cd folder-name` — move into a directory
- `cd ..` — move back one directory
- `cat filename.txt` — read a file
- `pwd` — show your current location

Good luck!

(And if you're interested in reading more about the episodes referenced in this maze, you can find the transcripts [here!](https://snarp.github.io/magnus_archives_transcripts/))
